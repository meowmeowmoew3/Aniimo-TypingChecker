# Aniimo Weakness Checker

A small static website for checking element weaknesses and strengths in **Aniimo**. Search an Aniimo (or pick elements by hand) and see how much damage it takes from and deals to every element, shown as radar charts.

Unofficial fan project. Not affiliated with Pawprint Interactive Entertainment or Aniimo.

## Features

- **Search by Aniimo** by name, including every form (Highland, Snowfield, Prismana and so on), each with its own elements
- **Pick elements manually**: Element 1 on the left, Element 2 on the right
- **Defence and Attack radar charts** with multipliers from ×0.39 to ×2.56
- **Tap an element icon** to see how its number is worked out
- **Compare two Aniimo** with overlaid radars, a side-by-side table and a quick summary
- **Aniimo to bring** and **Tough against it** suggestions, filterable by role
- **Shareable links**: the URL stores your selection, and "Copy link" copies it
- **Light and dark theme**

## Notes

- Dual-type Aniimo multiply both elements together (for example 1.6 × 1.6 = 2.56).
- The game calls Electric "Lightning", Rock "Earth" and Holy "Light".
- The roster has 98 Aniimo, using the official wiki's names. Form elements come from the game files. Roles and stats are blank for a few newer entries.
- If a portrait is missing, the site shows an initial badge instead.
